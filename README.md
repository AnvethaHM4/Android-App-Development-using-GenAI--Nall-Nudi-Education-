# Nalla-Nudi

## Android App Development using GenAI – Nalla-Nudi Education

Nalla-Nudi is a Kannada-English technical dictionary app designed to help Kannada-medium students transition into English-based higher education. The app acts as a bridge between technical English vocabulary and simple Kannada explanations.

---

## Problem Statement

Students from Kannada-medium schools often face difficulty understanding technical English terms used in Science, Mathematics, and Commerce subjects. Standard dictionaries are too broad and do not provide contextual educational explanations.

Nalla-Nudi solves this problem by providing:

* Simple Kannada meanings
* Subject-wise filtering
* Pronunciation support
* Flashcard revision
* Offline learning support

---

## Features

* Technical word search
* Kannada meanings with explanations
* Word of the Day
* Subject filters

  * Science
  * Maths
  * Commerce
* Save difficult words
* Flashcard revision system
* Voice pronunciation using Text-To-Speech
* Professional Material 3 UI
* Bottom navigation bar
* Smooth scrolling using LazyColumn
* Fully offline functionality
